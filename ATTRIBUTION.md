## Electric-vehicle inspiration

The project was inspired in part by the gameplay idea and implementation
direction of the MIT-licensed [Electric Vehicles Factorio mod](https://mods.factorio.com/mod/electric-vehicles).

The current Biter Motors repository does not vendor, copy, or link against
that mod's source code or assets. The Biter Motors vehicle prototypes,
charging behavior, driving controls, audio, and runtime systems are maintained
as independent implementation. This attribution records inspiration only; it
is not a claim that code from Electric Vehicles is incorporated here.
